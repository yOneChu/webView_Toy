    HOW IT WORKS

    세 단계로 끝나는 BOM 무결성 점검

    호기를 고르면 나머지는 시스템이 처리합니다. 사람이 엑셀을 대조하던 시간을 감지와 판단에 씁니다.

    1. 01

      호기 선택

      브랜드·호기번호로 검색해 점검할 호기를 여러 개 한 번에 선택합니다.

    2. 02

      버전 비교

      자재번호 + BLOCK NO 기준으로 이전 버전과 현재 버전을 줄 단위로 대조합니다.

    3. 03

      이상 판정

      안전 블록 삭제, 수량 급변, 중복 등록 등 규칙으로 High·Medium·Low를 매깁니다.

    FEATURES

    무엇이, 어디서, 얼마나 바뀌었는지

    버전 간 Diff를 한눈에

    추가·삭제·수량·주석 변경을 색상과 아이콘으로 구분합니다.

    추가EL-2090-A0노이즈 필터 EMI0 → 1
    삭제EL-7002-A0비상정지장치2 → 0
    수량EL-5001-A0메인 로프 Ø106 → 18

    호기 샤프트 뷰

    BLOCK을 층으로, 변경이 몰린 층에 불이 켜집니다.

    규칙 기반 이상 판정

    변경을 위험도로 분류해 우선순위를 정합니다.

    • High안전장치(B70) 부품 삭제 · 수량 +100% 이상 또는 −50% 이하 (2개 이상 변동)
    • Medium수량 ±30% 변동 · 대체품 없는 삭제 · 동일 BLOCK 자재 중복
    • Low변경 사유(주석) 미갱신 · ECN 근거 없는 신규 부품

    최근 감지

    최신 버전 기준 우선 확인이 필요한 항목입니다.

    지금 호기를 선택하고 비교해 보세요.

    선택한 호기의 최신 BOM을 직전 버전과 즉시 대조합니다.
