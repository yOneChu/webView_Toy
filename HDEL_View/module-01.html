모듈러 도면 통합 조회
모듈러 프로젝트별 도면을 한 화면에서 조회하고, 버전·상태를 직관적으로 비교할 수 있는 전용 시스템입니다.
도면 버전관리
모듈 타입 비교
PLM / Vault 연계 전제
오늘 할 일 · 도면번호 & 프로젝트만 입력하면 현재 설계 상태를 빠르게 확인할 수 있습니다.
조회 TIP
  • · 프로젝트명, 도면번호 중 하나만 입력해도 조회 가능합니다.
  • · 모듈 타입(예: 모듈러 샤프트, 모듈러 기계실)을 필터링하면 속도가 더 빨라집니다.
  • · 도면 상태가 “릴리즈”인 항목만 별도 필터링 가능합니다.
※ 실제 데이터 연동은 PLM / Vault 팀과 협의 후 API 연계로 구현하면 됩니다.
